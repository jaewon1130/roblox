# RIVALS 성격 유형 검사

[`rivals-personality-test.html`](./rivals-personality-test.html)은 설치 없이 실행되는 단일 파일 검사 페이지입니다. 초·중등 남학생이 빠르게 답할 수 있도록 한 화면에 질문 하나씩만 보여 주고, 결과에는 유형별 이미지가 들어갈 자리를 마련했습니다.

## 바로 실행하기와 확인하기

1. `rivals-personality-test.html`을 더블 클릭해 Chrome 또는 Edge에서 엽니다.
2. 검사 시작 → 7문항 응답 → 결과와 다시 해보기, 결과 복사 버튼을 확인합니다.
3. 문제가 보이면 브라우저에서 `F12`를 눌러 **Console** 탭의 오류를 확인합니다.

별도 서버·회원가입·패키지 설치가 필요 없으며, 인터넷 연결이 끊겨도 검사 로직은 실행됩니다. 다만 나중에 온라인 이미지를 쓰거나 티스토리 iframe으로 연결할 때는 인터넷이 필요합니다.

개발자 도구 Console에서 아래처럼 입력하면 점수 계산을 직접 확인할 수 있습니다. 숫자 `0~3`은 각 문항의 A~D 선택지입니다.

```js
RIVALS_TEST([0, 3, 1, 2, 1, 0, 3])
```

출력의 `winner`가 최종 유형 코드, `scores`가 유형별 합산 점수, `tied`가 최고점 동점 유형입니다.

## 확정된 채점 방식

선택지마다 한 유형에만 다음 가중치를 더합니다. 모든 유형이 얻을 수 있는 최대 점수는 8점으로 맞췄습니다.

| 문항 | A | B | C | D |
|---|---|---|---|---|
| Q1 | 측면 대 측면 +1 | 당신에게서 +1 | 스텝 댄싱 +3 | 크리스 크로스 +3 |
| Q2 | 측면 대 측면 +1 | 포탈 오류 +3 | 탱고 +2 | 워프메이커 +2 |
| Q3 | 당신에게서 +3 | L을 가져가 +3 | 포탈 오류 +1 | 크리스 크로스 +2 |
| Q4 | 탱고 +1 | 당신에게서 +1 | 측면 대 측면 +3 | 스텝 댄싱 +3 |
| Q5 | 당신에게서 +3 | L을 가져가 +3 | 포탈 오류 +3 | 스텝 댄싱 +2 |
| Q6 | 측면 대 측면 +3 | 탱고 +2 | 워프메이커 +3 | 포탈 오류 +1 |
| Q7 | 탱고 +3 | 크리스 크로스 +3 | L을 가져가 +2 | 워프메이커 +3 |

최고점이 여러 유형이면 **Q7부터 Q1까지 거꾸로 확인해, 동점 유형 중 더 최근 문항에서 점수를 얻은 유형**을 결과로 정합니다. 이 규칙은 HTML의 `calculateResult` 함수에 구현되어 있습니다.

## 8개 결과 이미지 연결하기

HTML 파일과 같은 위치에 `images` 폴더를 만들고, 아래 이름으로 결과 이미지를 넣으면 자동으로 표시됩니다. PNG/JPG 모두 가능하지만 파일명과 코드의 경로는 일치해야 합니다.

| 유형 | 기본 파일 경로 |
|---|---|
| L을 가져가 | `images/l-eul-gajyeoga.png` |
| 크리스 크로스 | `images/criss-cross.png` |
| 측면 대 측면 | `images/side-by-side.png` |
| 포탈 오류 | `images/portal-error.png` |
| 스텝 댄싱 | `images/step-dancing.png` |
| 탱고 | `images/tango.png` |
| 당신에게서 | `images/dangsinegeseo.png` |
| 워프메이커 | `images/warp-maker.png` |

다른 파일명을 쓸 경우 HTML의 `const TYPES` 안에서 해당 유형의 `image:` 값만 수정하면 됩니다. 이미지가 없거나 경로가 틀려도 검사는 멈추지 않고, 유형별 색상과 아이콘 카드가 대신 보입니다. 세로 3:4 비율 이미지를 권장합니다.

## 티스토리에 넣는 방법

티스토리 글 본문은 보안상 JavaScript 실행을 제한하므로, 이 HTML 전체를 글 본문에 붙여 넣는 방식은 안정적이지 않습니다. 아래 두 방식 중 하나를 추천합니다.

### 1) 외부 호스팅 + iframe (추천)

GitHub Pages, Netlify, Cloudflare Pages 같은 정적 웹 호스팅에 `rivals-personality-test.html`과 `images` 폴더를 올립니다. 공개 주소가 예를 들어 `https://example.github.io/rivals/`가 되면, 티스토리의 HTML 모드에 다음만 넣습니다.

```html
<iframe
  src="https://example.github.io/rivals/"
  title="RIVALS 성격 유형 검사"
  width="100%"
  height="880"
  style="border:0; max-width:720px; display:block; margin:0 auto;"
  loading="lazy">
</iframe>
```

장점은 코드와 이미지를 한 곳에서 관리하고 고칠 수 있다는 점입니다. 티스토리 글에는 iframe만 두면 됩니다. 모바일에서 결과 카드가 길어질 수 있으므로 처음에는 `height="880"`으로 올린 뒤 실제로 휴대폰에서 확인하고 필요하면 높이를 늘리세요.

### 2) 별도 웹페이지로 링크하기

iframe이 스킨이나 편집기에서 제거·제한되는 경우, 티스토리 글에는 “검사하러 가기” 버튼/링크만 넣고 새 탭에서 외부 호스팅 페이지를 여는 방식이 가장 호환성이 좋습니다.

```html
<a href="https://example.github.io/rivals/" target="_blank" rel="noopener">RIVALS 유형 검사하러 가기</a>
```

## 티스토리 적용의 한계

- 티스토리의 에디터/스킨 정책에 따라 `iframe`, 인라인 스타일, 스크립트가 제거되거나 표시 방식이 달라질 수 있습니다. 게시 전 비공개 글 또는 미리보기와 모바일 화면에서 확인하세요.
- 외부 호스팅이 HTTPS여야 티스토리 HTTPS 글에서 차단되지 않습니다.
- 이 파일은 개인 정보를 서버로 보내거나 저장하지 않습니다. 방문 수, 결과별 통계 같은 기능을 원하면 별도의 분석 도구 또는 서버가 필요합니다.
- 실제 티스토리 로그인·글 발행은 이 작업에 포함하지 않았습니다. 계정 권한이 필요한 외부 변경이기 때문입니다.
